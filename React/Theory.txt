React JS
Components : are building blocks of React JS. 
They are reusable pieces of code that represent a part of the user interface. 
Components can be functional or class-based, 
and they can accept inputs called props to customize their behavior and appearance.

props : are short for properties and are used to pass data from a parent component to a child component.

state : is a built-in object that allows components to manage and track their own data.

Hooks : are functions that let you use state and other React features in functional components. 
Common hooks include useState, useEffect, and useContext.

useState : is a hook that allows you to add state to functional components.
useEffect : is a hook that allows you to perform side effects in functional components, 
such as fetching data or subscribing to events.
    - useEffect takes two arguments: a callback function and an optional dependency array.
    - The callback function is executed after the component renders, and the dependency array determines when the effect should be re-run.

Dependency Array : is an optional second argument to the useEffect hook that specifies when the effect should be re-run.
    - Empty dependency array ([]) means the effect runs only once after the initial render, 
    - Dependency Array with values means the effect runs whenever any of the specified dependencies change.
    - No Dependency Array means the effect runs after every render, which can lead to performance issues if not used carefully.

Prop Drilling : is the process of passing data from a parent component to a deeply nested child component through multiple layers of components.
useContext : is a hook that allows you to share state and data between components without prop drilling.
    - It provides a way to create a global state that can be accessed by any component in the component tree.


React Component lifecycle : refers to the different stages a component goes through during its existence, from creation to destruction.
    - Mounting: The component is being created and inserted into the DOM.
    - Updating: The component is being re-rendered due to changes in props or state.
    - Unmounting: The component is being removed from the DOM.


useMemo and useCallback : are hooks that help optimize performance by memoizing values and functions.
    - useMemo: is a hook that memoizes the result of a computation, preventing unnecessary recalculations on re-renders.
    - useCallback: is a hook that memoizes a function, preventing unnecessary re-creations of the function on re-renders.

useRef : is a hook that provides a way to create a mutable reference that persists across renders.
    - It can be used to access DOM elements directly or to store mutable values that do not trigger re-renders.

custom hooks : are user-defined hooks that allow you to extract and reuse logic across multiple components.
    - They follow the same rules as built-in hooks and can help keep your code organized and maintainable.



Redux : is a state management library for JavaScript applications, often used with React.
    - It provides a predictable state container that helps manage the state of an application in a centralized way.
    
    State : Actual Data
    Store : Single source of truth
    Dispatch : Function that sends an action to the store to update the state -> useDispatch()
    Action : JavaScript object that describes a change in state -> {}
    Reducer : A pure function that takes the current state and an action as arguments and returns a new state based on the action.
    Selector : A function that extracts specific pieces of state from the Redux store, allowing components to access only the data they need. -> useSelector()

    Slice : A slice is a portion of the Redux store that manages a specific piece of state.
    Aync Actions : are actions that involve asynchronous operations, such as API calls or timeouts.
    thunk middleware : is a middleware that allows you to write action creators that return a function instead of an action object.
    payload : is the data that is sent along with an action to provide additional information for the reducer to update the state.
